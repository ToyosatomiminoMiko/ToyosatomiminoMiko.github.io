## meta

思考过程和回答使用中文

整体风格: 参考 RMS & Stroustrup
保持文件的独立性,模块化设计
代码注释使用中文
全项目禁止使用全角标点符号
遵守以下字符替换规则:

```json
{
  ")":")",
  "(":"(",
  "，":",",
  "。":"",
  "“":"\"",
  "”":"\"",
  "‘":"'",
  "；":";",
  "—":"-"
}
```

- html
尽量不要在当中写css,js
应当使用外部js,css,尽量不要使用html行内样式

- js
代码顺序:类定义,函数定义,表达式,语句,注册事件
